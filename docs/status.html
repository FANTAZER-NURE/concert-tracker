Holes in the last step

  • Venue fields from Ticketmaster never create a Venue row.
  • Continent is never set, so NA/US subscriptions cannot match on stored events yet.
  • Incomplete SourceEntry rows are marked processed=true and dropped.
  • Social sources in seed get a daily stub entry, then that stub is discarded.
  • Same show from two sources would become two events.
  • Connector choice is source.name === 'Ticketmaster'.
